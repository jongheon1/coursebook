# quiz

인자: `<course-slug> [주차 번호|all]` (생략 시 과목의 전체 주차에서 섞어서 출제)

## 절차

1. 대상 과목의 `weeks/*/quiz.md` (해당 주차 또는 전체)를 읽는다. `semester/*/delta.md` 가 있으면 Emphasized 항목 문항을 우선 출제한다 (시험 신호).
2. 한 번에 **한 문제씩** 낸다. 절대 답을 먼저 보여주지 않는다.
3. 사용자가 답하면: 정오 판정 → 부족한 부분만 짚어서 보완 설명 (전체 해설 반복 금지) → 다음 문제.
   - 사용자가 "모름"이면 답을 알려주되, 세션 끝에 그 문항을 변형해서 재출제한다.
4. 기본 10문항. 세션 끝에 요약: 맞은 것/틀린 것/재출제 결과, 약한 토픽과 다시 읽을 챕터 섹션 링크.
5. 틀린 문항은 `<course-dir>/semester/quiz-log.md` 에 날짜와 함께 누적한다 (다음 세션에서 우선 출제 — spaced repetition). 커밋은 사용자가 원할 때만.

## 출제 규칙

- 문항을 quiz.md 그대로 읽지 말고 표현을 바꿔서 (암기가 아니라 이해를 테스트).
- 서술형 위주. 사용자가 영어 답안 연습을 원하면 문제를 영어로 낸다.
